# Mission launch 

First, launch the controllers, hardware interface and gazebo:

`ros2 launch ros_deep_sampler gazebo2.launch.py`

After that, launch the mission node:

`ros2 launch ros_deep_sampler mission.launch.py`

Operation described in `terminal_commands.md` and `mission_control_logic.md` \
Can interface described in `sampler_hardware_interfaces\docs\can_communication.md`
